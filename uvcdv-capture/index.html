uvcdv-capture

Captures MiniDV tapes over USB on a Mac that has no FireWire. The .dv files come out bit for bit the same as a FireWire capture would give.

Install ▶Source on GitHub

I have a box of MiniDV tapes and a Panasonic NV-GS330 camcorder. The proper way to capture MiniDV is FireWire, which modern Macs don’t have and Apple removed from macOS. Analog capture digitizes the picture again and loses quality. Some Panasonic camcorders from the mid-2000s can send the same digital stream over plain USB, in a mode called Motion DV. Windows and Linux read it. On a Mac the camera shows up, but no capture device appears, because Apple’s driver doesn’t implement that format.

uvcdv-capture reads the stream through libusb, with no drivers and no kernel extensions, and writes .dv files bit for bit as a FireWire capture would. It counts every lost packet; a clean capture shows drop=0 ovf=0, and dvrescue finds no damaged frames.

What it does

  • Captures to raw .dv, the archival master every DV tool understands, with the sound, the timecode and the recording dates inside.
  • Controls the tape over the same USB cable: play, pause, stop, rewind, fast-forward, and reads the timecode without capturing. In Scenalyzer on a PC I could start and stop the tape on this same camera, so I asked for it here too.
  • Digitizes a whole tape hands-free: starts playback, captures until the recording ends and stops the tape.
  • Splits the capture into one file per recorded clip, by the jumps in timecode and recording date.
  • Encodes MP4 on the fly, 6 to 8 times smaller than raw DV, with optional deinterlacing or a 720p 50 fps version ready for YouTube. For editing there is ProRes 422 HQ instead.
  • Replaces the camera’s sound with a separate recorder’s, found and synced for every scene.
  • Adjusts the picture with sliders that work live, even mid-capture, and corrects each scene automatically. I filmed a concert in the dark; the first night mode made it brighter but noisy, and the picture kept changing. The one that stayed applies one fixed shadow curve per scene.
  • Turns DV into a worn VHS capture with --vhs, by simulating the signal path from the camcorder through the tape and the cable to a capture card, not with a retro filter.
  • Does all of this from the command line or in a native Mac app, in English or Russian.

The one command most people need

uvcdv-capture --play --stop --idle 15 tape01.dv

It starts the tape, captures until the recording ends and stops the tape. One hour of tape is about 13 GB as raw DV, or about 1.7 GB with tape01.mp4 as the output.

What you need

  • A Panasonic MiniDV camcorder with USB FUNCTION set to Motion DV (the NV-GS and PV-GS series), on the AC adapter.
  • A Mac with Apple Silicon. On Intel it should work through Homebrew, but nobody has tried yet.
  • ffmpeg for MP4 and the preview: brew install ffmpeg.
brew tap boris-timofeenko/tap && brew trust boris-timofeenko/tap && brew install uvcdv-capture

What it can’t do

  • Sony “USB Streaming”, JVC and Canon camcorders don’t send DV over USB at all, so it can’t capture from them.
  • I have tested it end to end only on my NV-GS330. If your camera has a DV-over-USB mode, the README explains how to check it in a minute.
  • The prebuilt binaries are not code-signed, so macOS asks before the first launch; Homebrew builds from source and doesn’t.
